# Privacy Policy

**Project:** ronin-issen — the SecurityRonin forensic fleet (governance umbrella)
**Effective date:** 2026-07-29
**Operator:** Security Ronin Ltd

`ronin-issen` is a documentation and governance repository — the map of the
SecurityRonin forensic fleet and the home of its architecture decisions. It is not a
product, ships no binary, operates no server or backend, and collects no data.

The forensic tools it catalogues (Issen and the component libraries) are local
command-line software: they run on your machine, on evidence you provide, and do not
transmit data to Security Ronin or any third party. Each tool's own repository carries
its specific privacy notice.

No telemetry, no analytics, no phone-home — here or in any fleet component.
